# IRL Games

A customizable real-life game platform.

## V0.1.1

- Home screen
- Create Lobby
- Join Lobby
- Host, Player, and Host + Player modes
- Random 6-character lobby codes
- Real QR-code generation
- Join links
- Player name entry
- Player lists
- Basic game-setup screen

## Architecture

Players -> Roles -> Tasks -> Abilities -> Objects -> Boundaries -> Events -> Logic -> Scoring

The first game will be a Murder Mystery-style game. Later templates can include Capture the Flag, Infection, Hide & Seek, and custom games.

## Current limitation

V0.1.1 is a frontend prototype. A lobby created on one device is not synchronized with a different device yet. A realtime backend/database is the next major technical step.

## Files

- index.html - page structure
- style.css - visual design
- script.js - frontend behavior
